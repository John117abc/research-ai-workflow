# 01 · 开始一个新研究

> **用在哪**：你决定开一个新课题时。
> **怎么用**：把下面代码块整段发给 AI，只替换 `<...>` 部分。AI 需要能读到你本地的 `research-ai-workflow`。
> **别省掉的那句**：`不写代码、不建分支、不装依赖`——省了它，AI 常常会先动起来再问你。

```
我要开一个新研究。

协议仓库：<research-ai-workflow 的绝对路径或 git 地址>
本地路径：<新建项目打算放在哪，可为空，让 AI 建议>

研究方向（一句话，可以很模糊）：<填>

请按该仓库 PROTOCOL.md §10「开新研究」执行，分三步，每步等我确认：

1. 先读 §10，然后按 10.1 问我：这次用「一个仓库 + 目录分离」还是「两个仓库」？
   列出你判断的依据。不要替我决定。
2. 我回答后，按 10.2 建目录、10.3 起草三个文件。
   其中「可证伪条件」和「明确非目标」由我定稿，你只起草候选，
   未确认的一律写 <待研究者确认>。
3. 最后按 10.4 空手跑一次 §1，把「状态 / 上次 / 未决 / 建议」四句给我验收。

在我说「开始」之前：不写代码、不建分支、不装依赖。
```

## 退化方案：AI 读不到本地文件时

（例如网页版 ChatGPT）

把这三样贴给它，代替 `PROTOCOL.md`：

1. `PROTOCOL.md` §10 全文（开新研究五节）
2. `templates/` 下五个文件 + `state.yml` 的空白模板
3. 一句话：`按上面的协议初始化，先问我拓扑，再动手`

## 验收标准

初始化完，它必须能**空手**说出：

```
状态：IDEATION · 轮次 NONE
上次：仓库刚初始化
未决：可证伪条件、非目标待定
建议：…
```

说不出、或者只会说"我已经准备好了"——**初始化没做对，先修，别开始研究**。
