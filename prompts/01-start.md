# 01 · 开始一个新研究

> **用在哪**：你决定开一个新课题时。
> **怎么用**：先在 GitHub 建一个**空的私有仓库**（新项目），然后把下面代码块整段发给 AI，只替换 `<...>` 部分。
> **别省掉的那句**：`不写代码、不建分支、不装依赖`——省了它，AI 常常会先动起来再问你。

```
我要开一个新研究。

协议仓库：git@github.com:John117abc/research-ai-workflow.git
新项目仓库：git@github.com:John117abc/<新项目名>.git
本地位置：<空着让 AI 建议，或写路径>
研究方向（一句话，可以很模糊）：<填>

请按该仓库 PROTOCOL.md §10「开新研究」执行，按下面 0–3 步，每步等我确认：

0. 先按 §1 第 0 步核对仓库：clone 新项目仓库到本地位置，
   用 git remote -v 确认指向的是新项目仓库（不是协议仓库）。
1. 按 10.1 直接用默认拓扑（一个仓库 + 目录分离），**不要问我这个**；
   除非我主动说了「代码要保密 / 文档要公开」或「代码有独立重依赖」。
   如果方向还没给，先问我一句话方向，也不要同时抛拓扑问题。
2. 按 10.2 建目录、10.3 起草三个文件。
   其中「可证伪条件」和「明确非目标」由我定稿，你只起草候选，
   未确认的一律写 <待研究者确认>。
3. 最后按 10.4 空手跑一次 §1，把「状态 / 上次 / 未决 / 建议」四句给我验收。

在我说「开始」之前：不写代码、不建分支、不装依赖。
```

## 怎么指路（三选一，按 AI 的能力挑）

| AI 在哪 | 怎么指 | 代价 |
|---|---|---|
| 本地（DSH / OpenCode / Claude Code），已 clone | 给**本地绝对路径** | 最快，能读整个仓库 |
| 本地，但没 clone | 给 **git 地址**，让它先 clone | 需要 SSH key 或 HTTPS 凭据 |
| 网页版（ChatGPT 等） | 给 **https 网页链接** | 只能读公开仓库；读不到你的**私有项目仓库** |

**判断顺序**：先问"它能不能读本地磁盘"。不能读 → 只能走网页链接或直接贴内容。

**为什么仓库地址优先于路径**：路径是缓存，换机器就失效；仓库是地址，长期有效。你如果把协议放进仓库却只用路径指路，等于白搬。

## 退化方案：AI 读不到本地文件时

（例如网页版 ChatGPT）

把这三样贴给它，代替 `PROTOCOL.md`：

1. `PROTOCOL.md` §10 全文（开新研究五节）
2. `templates/` 下五个文件 + `state.yml` 的空白模板
3. 一句话：`按上面的协议初始化；拓扑用默认（一个仓库）；方向未定就先问我方向`

## 验收标准

初始化完，它必须能**空手**说出：

```
状态：IDEATION · 轮次 NONE
上次：仓库刚初始化
未决：可证伪条件、非目标待定
建议：…
```

说不出、或者只会说"我已经准备好了"——**初始化没做对，先修，别开始研究**。
