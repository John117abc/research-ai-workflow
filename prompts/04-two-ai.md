# 04 · 设计侧 / 执行侧 分工（四个时刻）

> 适用：讨论与制定实验的 AI（设计侧）和跑实验的 AI（执行侧）不在同一台机器，或不是同一个模型。
> 规则来源：`PROTOCOL.md` §13。这里只给可直接粘贴的话术。

## 谁说什么，一句话

| 时刻 | 你对谁说 | 关键一句 |
|---|---|---|
| 新研究开始 | 设计侧 | 「你是设计侧，不跑实验、不改代码、不替我批准」 |
| 新研究开始 | 执行侧 | 「你负责执行；先做环境体检，等轮次文件」 |
| 继续 | 设计侧 | 「只读库、讨论、起草、审交接」 |
| 继续 | 执行侧 | 「status 不是 APPROVED 就停下」 |

**每段话必须包含三样**：仓库地址（不是本地路径）、你的角色、停手条件。缺任何一个，AI 就会自己往前走。

---

## 1 · 设计侧：开始新研究

```
我要开一个新研究。你是设计侧：不跑实验、不改代码、不替我批准、不宣布实验结论。

协议仓库：git@github.com:John117abc/research-ai-workflow.git
新项目仓库：git@github.com:John117abc/<新项目名>.git
本地位置：<可空着让你建议>
研究方向（一句话）：<填>

按 PROTOCOL §10「开新研究」执行，按下面 0–3 步，每步等我确认：

0. 按 §1 第 0 步核对仓库：clone 新项目仓库到本地位置，
   用 git remote -v 确认指向新项目仓库（不是协议仓库）。
1. 按 10.1 直接用默认拓扑（一个仓库 + 目录分离），不要问我这个；
   除非我主动说了「代码要保密 / 文档要公开」或「代码有独立重依赖」。
2. 按 10.2 建目录、10.3 起草三个文件。
   「可证伪条件」和「明确非目标」由我定稿，你只起草候选。
3. 按 10.4 空手跑一次 §1，给我四句汇报验收。

然后停下来，等我确认研究方向。这一轮不要出 ROUND。
在我说「开始」之前：不写代码、不建分支、不装依赖。
```

## 2 · 执行侧：第一次加入这个研究

```
这个研究由另一台机器上的 AI 负责讨论和制定实验，你负责执行。

项目仓库：git@github.com:John117abc/<新项目名>.git
本地位置：<填>

先读 PROTOCOL.md 的 §0 与 §13，确认你的角色是执行侧：
你不改研究问题、不定指标/基线/预算、不批准、不宣布结论。

你现在的任务只有三件：
1. clone 仓库，确认 git remote -v 指向项目仓库（不是协议仓库）
2. 环境体检：数据在哪、模型权重有没有、依赖能不能装、显存多少
   把「能跑什么」和「缺什么」列给我，不要开始写实验代码
3. 如果仓库里还没有 research/rounds/ 下的轮次文件，
   报告「等设计侧的 ROUND」，然后停下

禁止：自己决定研究目标、自己加实验、自己改指标。
```

## 3 · 设计侧：继续

```
继续这个研究。你是设计侧。

项目仓库：<本地绝对路径>
先按 prompts/02-resume.md 走（读序 + 四句汇报），再按 §13 限定角色：
只读库、讨论、起草轮次、审交接；不跑实验、不改代码、不批准。

汇报完再告诉我三件事：
- 最近一轮是什么状态（DRAFT / APPROVED / EXECUTING / 待审）
- 有没有在等执行侧回传的东西
- 下一步该我出 ROUND，还是该执行侧跑
```

## 4 · 执行侧：继续

```
继续这个研究。你是执行侧。

项目仓库：<本地绝对路径>

1. 按 §1 第 0 步确认仓库与 remote
2. git pull
3. 读 research/state.yml 和最新的 research/rounds/R*.md
4. 汇报：轮次号、它的 status、approval_quote 里有没有我给的原文
5. 若 status 不是 APPROVED，或 approval_quote 为 NONE → 停下等我批准，不要动手
6. 若是 APPROVED → 按 §2.5 执行：
   动手前四要素、B 级改动先给变更预告（五格 + 人话）、理解校验、开关 + 台账

禁止：自己开新一轮、自己改指标、自己宣布结论、跑完直接 push 不写交接。
```

---

## 最常见的三种走偏

| 现象 | 原因 | 打断语 |
|---|---|---|
| 执行侧自己写了个新实验 | 没给它「等 ROUND」的停手条件 | 「停。等你拿到 APPROVED 轮次之前，不许写实验代码。」 |
| 设计侧填了 approval_quote | 它以为「研究者刚才同意了」就是批准 | 「批准只能在执行侧填，撤回这一格。」 |
| 执行侧跑完只在聊天里说结果 | 它不知道结果必须落进交接 | 「把结果写进 ROUND 的交接章节并 push，聊天里的不算。」 |
